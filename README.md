# Advanced Excel & Data Analytics Practice Repository (DA103)

This repository contains practice files, concept sheets, exercises, and assignments organized across sprints to build hands-on skills in spreadsheet operations, data cleaning, analysis, and visualization.

---

## Sprints & Topics Covered

### Sprint 1 — Spreadsheet Foundations, Sorting, Filtering & Data Exploration
* **Course Details & Concept Practice** (`DA103_S1_CourseDetail_Data_Concept.xlsx`, `DA103_S1_CourseDetail_Data_Concept (1).xlsx`)
* **Movies Dataset Practice** (`DA103_S1_Movies_Data_Practice.xlsx`, `DA103_S1_Movies_Data_Practice (1).xlsx`)
* **Pizza Concept & Solution** (`DA103_S1_Pizza_Concept_Solution.xlsx`)
* **Key Focus Areas:** Navigating worksheets, sorting and filtering records, basic formulas, summarizing structured tables, and reviewing guided solutions.

### Sprint 2 — Demo & Hands-On Practice
* **Demo Practice File** (`DA_AI_C1_S2_demo_practise.xlsx`)
* **Key Focus Areas:** Applying core spreadsheet techniques through guided demonstrations and practical data exercises.

### Sprint 4 — Data Practice
* **Practice Datafile** (`DA103_C1_S4_Datafile_Practice.xlsx`)
* **Key Focus Areas:** Working with multi-page practice datasets to reinforce data manipulation and analytical workflows.

### Sprint 8 — Practice Assignment
* **Practice Assignment Datafile** (`DA103_C1_S8_Datafile_Practice_Assignment .xlsx`)
* **Key Focus Areas:** Independent problem-solving and applying learned Excel/data analytics techniques to assignment datasets.

### Sprint 9 — Data Practice
* **Practice Datafile** (`DA103_C1_S9_Datafile_Practice.xlsx`)
* **Key Focus Areas:** Deeper analytical practice, formula/function application, and working with structured datasets across multiple views.

### Sprint 10 — Data Practice
* **Practice Datafile** (`DA103_C1_S10_Datafile_Practice.xlsx`)
* **Key Focus Areas:** Consolidating data analysis skills with multi-part practice sheets and analytical tasks.

## How to Use
1. Open the workbook for the corresponding sprint in **Microsoft Excel** (or a compatible spreadsheet tool).
2. Review any concept or solution sheets first (such as in Sprint 1) before attempting practice and assignment sheets.
3. Keep raw data sheets intact and perform transformations, formulas, or summaries cleanly in dedicated columns or sheets.
